# rubikscube
Software based on Python to grid and cut a rubik's cube's fresco for assembly schematics.

## Exemple
1. Download [this picture](https://github.com/benoitdekeyn/rubikscube/blob/main/frescoTeam3.png)
2. Download the executable version [Grider.exe](https://github.com/benoitdekeyn/rubikscube/raw/refs/heads/main/Grider%C2%AE.exe)
3. Execute Grider, drag-and-drop the picture into the terminal, press enter.
4. The dimmensions of this picture in terms of rubik's cubes is 87 * 33. Then you can input 4 columns * 2 rows.
5. 9 pictures should have been created ready to be spread among the different teams.

## Warning
Pictures need to have very specific dimmensions : 
width  in pixel = 150 * Nummber of rubik's cubes it has been made for.
height in pixel = 150 * Nummber of rubik's cubes it has been made for.
